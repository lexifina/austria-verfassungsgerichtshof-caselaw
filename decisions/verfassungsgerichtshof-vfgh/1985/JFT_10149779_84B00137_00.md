# Verfassungsgerichtshof (VfGH) B137/84

Gericht
Verfassungsgerichtshof

Entscheidungsdatum
21.02.1985

Geschäftszahl
B137/84

Sammlungsnummer
10324

Leitsatz
ZivildienstG; keine Glaubhaftmachung von Gewissensgründen; keine Verletzung der verfassungsgesetzlich gewährleisteten Rechte auf Befreiung von der Wehrpflicht zwecks Zivildienstleistung und auf Gleichheit

Spruch
Die Beschwerde wird abgewiesen.
